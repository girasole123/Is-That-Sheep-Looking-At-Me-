# ITSLAM
Is That Sheep Looking At Me?

A P2P game based on the card game by Zedaph and DotDotDash.

You need an HTTP server for the P2P functionality to work. You can run one locally, for example with `python3 -m http.server`.

For more information:
- See the Kikstarter page of the card game: https://www.kickstarter.com/projects/creocards/is-that-sheep-looking-at-me-the-card-game
- See how-to-play video by Zedaph: https://www.youtube.com/watch?v=0o2nsB1hVK0

There are still some bugs, so any help in improving the code is greatly appreciated.
